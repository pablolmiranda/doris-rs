## Cross-cutting

- **NULL**: every function here uses the default IFunction NULL handling (a NULL argument gives a NULL row). There are no
  domain-error NULLs except in **log10, log2, ln** (`x <= 0`, `function_math_log.h:56-58`; NaN is not `<= 0`, so it gives NaN),
  **log(a,b)** (`a<=0 || b<=0 || |a-1|<1e-9`, math.cpp:556-565), **fmod/mod** (`b == 0`) and **conv** (bad base). None of these
  functions raise errors on values, except format_round's places check.
- **Return nullability (FE)**: the plain unary DOUBLE functions return `DOUBLE` (not nullable), and are `DOUBLE?` only when the argument is.
  log10/log2/log(2-arg) return `DOUBLE?`, fmod `DOUBLE?`, conv `VARCHAR(65533)?`, sign `TINYINT`, signbit `BOOLEAN` (sent as `TPrimitiveType 2`, prints `0`/`1`),
  money_format `VARCHAR(65533)`, format_round `STRING(2147483643)`.
- **Doubles print shortest round-trip** (existing `row_text.rs`): `Infinity`, `-Infinity`, `NaN`, `1e+308`, `6.123233995736766e-17`.
- **DECIMAL→DOUBLE casts** (`(double)raw / 10^s`) are exact for every literal here (raw < 2^53).

### glibc ports (verified 0 mismatches against the container's libm, except sinh as noted)

GCC contracts `a*b+c` into an FMA on aarch64 (glibc builds with `-ffp-contract=fast`). **cbrt and expm1 only match with `mul_add`
at exactly these places.** `log1p` = `libm::log1p` (the fdlibm port matched every sample). `exp`/`log` passed in = core_math.

```rust
fn hi(x: f64) -> u32 { (x.to_bits() >> 32) as u32 }
fn lo(x: f64) -> u32 { x.to_bits() as u32 }
fn set_hi(x: f64, h: u32) -> f64 { f64::from_bits(((h as u64) << 32) | (x.to_bits() & 0xffff_ffff)) }

/// sysdeps/ieee754/dbl-64/s_cbrt.c
pub fn cbrt(x: f64) -> f64 {
    const CBRT2: f64 = 1.2599210498948731648;
    const SQR_CBRT2: f64 = 1.5874010519681994748;
    const FACTOR: [f64; 5] = [1.0 / SQR_CBRT2, 1.0 / CBRT2, 1.0, CBRT2, SQR_CBRT2];
    if x == 0.0 || !x.is_finite() { return x + x; }
    let (mut bits, mut adj) = (x.abs().to_bits(), 0); // frexp(|x|): xm in [0.5,1)
    if bits >> 52 == 0 { bits = (x.abs() * f64::from_bits(0x4350000000000000)).to_bits(); adj = -54; }
    let xe = ((bits >> 52) as i32) - 1022 + adj;
    let xm = f64::from_bits((bits & 0x000f_ffff_ffff_ffff) | (1022u64 << 52));
    let u = (-0.145263899385486377f64).mul_add(xm, 0.784932344976639262);
    let u = u.mul_add(xm, -1.83469277483613086);
    let u = u.mul_add(xm, 2.44693122563534430);
    let u = u.mul_add(xm, -2.11499494167371287);
    let u = u.mul_add(xm, 1.50819193781584896);
    let u = u.mul_add(xm, 0.354895765043919860);
    let t2 = u * u * u;
    let ym = u * (t2 + 2.0 * xm) / (2.0 * t2 + xm) * FACTOR[(2 + xe % 3) as usize]; // C % and / truncate
    let r = ym * 2f64.powi(xe / 3);
    if x < 0.0 { -r } else { r }
}

/// sysdeps/ieee754/dbl-64/s_expm1.c (fdlibm, glibc's estrin form)
pub fn expm1(mut x: f64) -> f64 {
    const Q: [f64; 6] = [1.0, -3.33333333333331316428e-02, 1.58730158725481460165e-03,
        -7.93650757867487942473e-05, 4.00821782732936239552e-06, -2.01099218183624371326e-07];
    const LN2_HI: f64 = 6.93147180369123816490e-01;
    const LN2_LO: f64 = 1.90821492927058770002e-10;
    const INVLN2: f64 = 1.44269504088896338700e+00;
    let mut hx = hi(x);
    let xsb = hx & 0x8000_0000;
    hx &= 0x7fff_ffff;
    if hx >= 0x4043687A {
        if hx >= 0x40862E42 {
            if hx >= 0x7ff00000 { return if ((hx & 0xfffff) | lo(x)) != 0 { x + x } else if xsb == 0 { x } else { -1.0 }; }
            if x > 7.09782712893383973096e+02 { return f64::INFINITY; }
        }
        if xsb != 0 { return 1.0e-300 - 1.0; }
    }
    let (k, c): (i32, f64);
    if hx > 0x3fd62e42 {
        let (h, l);
        if hx < 0x3FF0A2B2 {
            if xsb == 0 { h = x - LN2_HI; l = LN2_LO; k = 1; } else { h = x + LN2_HI; l = -LN2_LO; k = -1; }
        } else {
            k = INVLN2.mul_add(x, if xsb == 0 { 0.5 } else { -0.5 }) as i32;
            let t = k as f64;
            h = (-t).mul_add(LN2_HI, x);
            l = t * LN2_LO;
        }
        x = h - l;
        c = (h - x) - l;
    } else if hx < 0x3c900000 {
        return x;
    } else {
        k = 0;
        c = 0.0;
    }
    let hfx = 0.5 * x;
    let hxs = x * hfx;
    let r1 = hxs.mul_add(Q[1], 1.0);
    let h2 = hxs * hxs;
    let r2 = hxs.mul_add(Q[3], Q[2]);
    let h4 = h2 * h2;
    let r3 = hxs.mul_add(Q[5], Q[4]);
    let r1 = h4.mul_add(r3, h2.mul_add(r2, r1));
    let t = (-r1).mul_add(hfx, 3.0);
    let mut e = hxs * ((r1 - t) / (-x).mul_add(t, 6.0));
    if k == 0 { return x - x.mul_add(e, -hxs); }
    e = x.mul_add(e - c, -c);
    e -= hxs;
    if k == -1 { return 0.5 * (x - e) - 0.5; }
    if k == 1 { return if x < -0.25 { -2.0 * (e - (x + 0.5)) } else { 2.0f64.mul_add(x - e, 1.0) }; }
    let add_k = |y: f64| set_hi(y, hi(y).wrapping_add((k << 20) as u32));
    if k <= -2 || k > 56 { return add_k(1.0 - (e - x)) - 1.0; }
    if k < 20 {
        add_k(set_hi(1.0, 0x3ff00000 - (0x200000 >> k)) - (e - x)) // t = 1 - 2^-k
    } else {
        add_k(x - (e + f64::from_bits(((0x3ff - k) as u64) << 52)) + 1.0) // t = 2^-k
    }
}

/// e_sinh.c (fdlibm)
pub fn sinh(x: f64, exp: fn(f64) -> f64) -> f64 {
    let ix = hi(x) & 0x7fff_ffff;
    if ix >= 0x7ff00000 { return x + x; }
    let h = if x.is_sign_negative() { -0.5 } else { 0.5 };
    if ix < 0x40360000 {                       // |x| < 22
        if ix < 0x3e300000 { return x; }       // |x| < 2^-28
        let t = expm1(x.abs());
        if ix < 0x3ff00000 { return h * (2.0 * t - t * t / (t + 1.0)); }
        return h * (t + t / (t + 1.0));
    }
    if ix < 0x40862e42 { return h * exp(x.abs()); }
    if ix < 0x408633ce || (ix == 0x408633ce && lo(x) <= 0x8fb9f87d) { let w = exp(0.5 * x.abs()); let t = h * w; return t * w; }
    x * 1.0e307
}

/// e_cosh.c (fdlibm)
pub fn cosh(x: f64, exp: fn(f64) -> f64) -> f64 {
    let ix = hi(x) & 0x7fff_ffff;
    if ix < 0x40360000 {
        if ix < 0x3fd62e43 {
            if ix < 0x3c800000 { return 1.0; }
            let t = expm1(x.abs());
            let w = 1.0 + t;
            return 1.0 + (t * t) / (w + w);
        }
        let t = exp(x.abs());
        return 0.5 * t + 0.5 / t;
    }
    if ix < 0x40862e42 { return 0.5 * exp(x.abs()); }
    if ix < 0x408633ce || (ix == 0x408633ce && lo(x) <= 0x8fb9f87d) { let w = exp(0.5 * x.abs()); let t = 0.5 * w; return t * w; }
    if ix >= 0x7ff00000 { return x * x; }
    f64::INFINITY
}

/// s_tanh.c (fdlibm)
pub fn tanh(x: f64) -> f64 {
    let ix = hi(x) & 0x7fff_ffff;
    if ix >= 0x7ff00000 { return if x.is_sign_negative() { 1.0 / x - 1.0 } else { 1.0 / x + 1.0 }; }
    let z = if ix < 0x40360000 {
        if x == 0.0 { return x; }
        if ix < 0x3c800000 { return x * (1.0 + x); }
        if ix >= 0x3ff00000 { let t = expm1(2.0 * x.abs()); 1.0 - 2.0 / (t + 2.0) }
        else { let t = expm1(-2.0 * x.abs()); -t / (t + 2.0) }
    } else { 1.0 - 1.0e-300 };
    if x.is_sign_negative() { -z } else { z }
}

/// s_asinh.c (fdlibm)
pub fn asinh(x: f64, log: fn(f64) -> f64) -> f64 {
    let ix = hi(x) & 0x7fff_ffff;
    if ix < 0x3e300000 { return x; }
    let w = if ix > 0x41b00000 {
        if ix >= 0x7ff00000 { return x + x; }
        log(x.abs()) + 6.93147180559945286227e-01
    } else {
        let xa = x.abs();
        if ix > 0x40000000 { log(2.0 * xa + 1.0 / ((xa * xa + 1.0).sqrt() + xa)) }
        else { let t = xa * xa; libm::log1p(xa + t / (1.0 + (1.0 + t).sqrt())) }
    };
    w.copysign(x)
}

/// e_log10.c (fdlibm). The "<= 0 → NULL" rule is applied outside (function_math_log.h).
pub fn log10(mut x: f64, log: fn(f64) -> f64) -> f64 {
    const TWO54: f64 = 1.80143985094819840000e+16;
    const IVLN10: f64 = 4.34294481903251816668e-01;
    const LOG10_2HI: f64 = 3.01029995663611771306e-01;
    const LOG10_2LO: f64 = 3.69423907715893078616e-13;
    let mut hx = hi(x) as i32;
    let mut k = 0i32;
    if hx < 0x00100000 {
        if x == 0.0 { return -TWO54 / x.abs(); }
        if hx < 0 { return (x - x) / (x - x); }
        k -= 54;
        x *= TWO54;
        hx = hi(x) as i32;
    }
    if hx >= 0x7ff00000 { return x + x; }
    k += (hx >> 20) - 1023;
    let i = ((k as u32) >> 31) as i32;
    hx = (hx & 0x000fffff) | ((0x3ff - i) << 20);
    let y = (k + i) as f64;
    x = set_hi(x, hx as u32);
    let z = y * LOG10_2LO + IVLN10 * log(x);   // matched every sample uncontracted
    z + y * LOG10_2HI
}
```

### conv — function_conv.cpp:57-222, exprs/math_functions.cpp:101-179, util/string_parser.hpp:599-650
Signatures: `conv(BIGINT, TINYINT, TINYINT)` and `conv(VARCHAR/STRING, TINYINT, TINYINT)` → `VARCHAR(65533)?` (always nullable).
Base check (per row, or once if both bases are constant): `|src| < 2 || |src| > 36 || |dst| < 2 || |dst| > 36` → NULL.
**BIGINT input** `num`:
1. `src < 0 && num >= 0` → NULL.
2. If `src != 10`: read the decimal digits of `|num|`, most significant first, as base-`src` digits, **stopping at the first digit ≥ src**
   (the prefix is kept). Accumulate in u64; on overflow `decimal_num = -1`. The sign of `num` is reapplied: `num < 0 ? 0 - value : value`.
3. Output `decimal_to_base(decimal_num, dst)`.

**String input**:
1. Cut the string at the first `.` (before trimming).
2. Trim ASCII whitespace (` \t\n\v\f\r`) on both ends.
3. Parse as `uint64` in base `src` (`string_to_int_internal<uint64_t>`). An empty string is FAILURE. An optional leading `-` or `+`.
   For each char: digit = `0-9`, `a-z`/`A-Z` → 10..35; any other char → FAILURE if it is the first digit position or the rest is not all whitespace, else stop.
   **Stop (SUCCESS) at the first digit ≥ base.** The overflow test is `val > max_div_base - (digit > max_mod_base)` in u64, where `max_val = u64::MAX`, **but with a
   leading `-`, `max_val = u64::MAX + 1 = 0`**, so `max_div_base = max_mod_base = 0`. A nonzero digit then never overflows, but **a `0` digit
   after a nonzero value overflows** (`'-10'` → OVERFLOW; `'-12'` → −12). Result: `negative ? -val : val` (wrapping), reinterpreted as i64.
4. `src < 0 && decimal_num >= 0` → NULL.
5. OVERFLOW → `decimal_num = -1` (whatever the sign of dst: u64::MAX assigned to an int64). FAILURE → the string `"0"`. Otherwise `decimal_to_base`.

`decimal_to_base(n, dst)`: `t = n as u64`. If `dst < 0 && n < 0`, `t = 0 - t` and prefix `-`. Digits of `t` in base `|dst|`, uppercase `0-9A-Z`, no leading zeros (`0` → `"0"`).

("777",8,10)→`511`, ("0",10,2)→`0`, ("Z",36,10)→`35`, ("9223372036854775807",10,16)→`7FFFFFFFFFFFFFFF`. Every call is sent in both runs.
**Hidden need:** `CAST(DOUBLE 1e308 AS VARCHAR)` must give `1e+308` (the BE's double-to-string), or conv sees another prefix.

## Risks and things that cannot be matched exactly

1. **libm parity.** Even with the ports, exp/sin/cos/tan (and sinh/cosh above 22, which call exp) use core_math, which disagrees with glibc 2.35 on ≈0.1–0.2% of
   random inputs. No recorded value is affected. A full fix needs ports of glibc's `e_exp.c` (with its data table) and the IBM sin/cos/tan, or running
   doris-rs against the container's libm. The perl oracle (`scratchpad/b5/libm.pl`) can generate pinned test vectors for any input.
2. **FMA dependence.** The cbrt and expm1 ports only match with `mul_add` exactly where GCC contracted. Keep them as written. If they are rewritten,
   re-verify against the container.
3. **money_format(DOUBLE inf/NaN)** reads out of bounds in C++ (size_t underflow in `do_money_format`). Its output is unspecified and it is not in the corpus.
   For **format_round(DOUBLE inf/NaN)**, C++ prints fmt's `inf`/`-inf`/`nan` (`-nan` for a negative NaN): special-case it, Rust prints `NaN`.
4. **format_round int truncations** (`static_cast<int>`, `exp10_i32` saturating at `i32::MAX`, `abs(INT_MIN)`) are bug-compatible requirements. `abs(INT_MIN)`
   is UB in C++; in practice it stays `INT_MIN` and gives non-digit characters (`'0' + negative`). It cannot be matched meaningfully and is not in the corpus.
5. **conv with a negative src base** goes through the same parser with a negative `int` base converted to u64 inside comparisons (undefined-looking). Out of
   corpus; NULL whenever the parsed value is ≥ 0.
6. **lcm overflow** wraps modulo 2^bits (libstdc++ computes in the unsigned type). Out of corpus.
7. The fold suite has **no expected `.out`**; grading uses the recorded C++ rows only (the dumps above).
