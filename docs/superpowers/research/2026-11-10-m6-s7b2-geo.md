## 1. st_point
- Args: x = longitude, y = latitude (DOUBLE columns; FE casts other types).
- Validity: `abs(x) <= 180 && abs(y) <= 90`; otherwise (also NaN, ±inf) the row is **NULL** (no error).
- Returns Nullable(String) always (null map built per row). NULL input -> NULL (IFunction default
  null handling; FE PropagateNullLiteral also folds literal NULL).
- Encoding (26 bytes): `0x00` (reserved) `0x01` (GEO_SHAPE_POINT) then memcpy of S2Point =
  3 x f64 little-endian (x, y, z) unit vector — NOT lat/lng.
  e.g. ST_Point(24.7,56.7) -> 000107a4031b34ecdf3f49ffb95a965dcd3f17a65a14efbeea3f (macOS libm; glibc may differ in last bit).
- Point = S2LatLng::FromDegrees(lat=y, lng=x).ToPoint().

## 2. st_astext / st_aswkt
- GeoShape::from_encoded: size<2 or byte0!=0 or unknown type or decode fails (point: size != 24) -> NULL.
- GeoPoint::as_wkt = "POINT (" + print_s2point + ")":
  ```cpp
  S2LatLng coord(point);
  os << std::setprecision(15) << coord.lng().degrees() << " " << coord.lat().degrees();
  ```
  i.e. printf `%.15g` semantics (default floatfield): 15 significant digits, round-half-even on the
  exact binary value, trailing zeros and trailing '.' stripped, scientific when exp10 < -4 or >= 15,
  exponent at least 2 digits with sign ("1e-05", "1e-07"), negative zero prints "-0", nan "nan", inf "inf".
- Rust recipe for %.15g:
  ```rust
  fn g15(v: f64) -> String {
      if v.is_nan() { return "nan".into(); }               // (unreachable for valid points)
      if v.is_infinite() { return if v < 0.0 {"-inf"} else {"inf"}.into(); }
      if v == 0.0 { return if v.is_sign_negative() {"-0"} else {"0"}.into(); }
      let s = format!("{:.14e}", v);                     // exact, correctly rounded, 15 sig digits
      let (m, e) = s.split_once('e').unwrap();
      let x: i32 = e.parse().unwrap();
      let strip = |t: &str| if t.contains('.') { t.trim_end_matches('0').trim_end_matches('.').to_string() } else { t.to_string() };
      if x < -4 || x >= 15 {
          format!("{}e{}{:02}", strip(m), if x < 0 {'-'} else {'+'}, x.abs())
      } else {
          strip(&format!("{:.*}", (14 - x) as usize, v))
      }
  }
  ```
  (Rust's `{:.Ne}` / `{:.N}` are exact-decimal correctly rounded with ties-to-even, matching glibc printf.
  Use x from the rounded `{:.14e}` — e.g. 999999999999999.9 rounds to 1e+15.)
  Existing crates/doris-exec/src/row_text.rs does shortest-repr %g; this needs precision 15 instead.

## 3. S2 math (v0.10.0), exact formulas
```
S1Angle::Degrees(d)  = (M_PI / 180) * d          // constant folded: 0.017453292519943295 * d
S1Angle::degrees()   = (180 / M_PI) * radians    // 57.29577951308232 * r
FromDegrees(lat,lng) = S2LatLng(Degrees(lat), Degrees(lng))
ToPoint():  phi = lat_rad; theta = lng_rad; cosphi = cos(phi);
            return (cos(theta) * cosphi, sin(theta) * cosphi, sin(phi))
S2LatLng(p): lat = atan2(p.z, sqrt(p.x*p.x + p.y*p.y)); lng = atan2(p.y, p.x)
```
Rust: `let d2r = std::f64::consts::PI / 180.0; let r2d = 180.0 / std::f64::consts::PI;` then
the same expressions with f64::cos/sin/atan2/sqrt, keeping the operation order (r2d * rad, d2r * deg).
- The round trip is NOT exact in general: e.g. 123.12345678901234 -> 123.12345678901237;
  1 (lat 1, lng 1) -> lng 0.9999999999999998. Printing at 15 digits hides these 1-3 ulp errors in
  every case tried; byte-exact only risks values whose 16th+ digits sit at a 15-digit rounding tie.
- libm: the reference BE (all-in-one 4.1.5, arm64 on this host) uses glibc sin/cos/atan2 (≤1 ulp,
  not guaranteed correctly rounded). Rust on Linux/glibc calls the same libm; on macOS a different
  libm — expect possible last-bit differences in the encoded bytes, not in the printed 15 digits.
- FMA: Latitude's `x*x + y*y` is inline in s2latlng.h, compiled into geo_types.cpp with BE flags;
  on aarch64 clang (-ffp-contract=on default) may fuse it to fma(x,x,y*y). BE CMakeLists only sets
  -ffp-contract=off for ARM in BE_TEST builds — hint that release ARM builds do contract. Affects only
  the latitude's last bit; invisible at %.15g for tested inputs. (Python on this host lacks math.fma so
  fused variant not simulated.)
